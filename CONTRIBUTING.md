# Contributing to Aether Labs

🎉 First off, thank you for considering contributing to Aether Labs! 

Your time, ideas, and code help us illuminate the universe faster.

## Code of Conduct

We are committed to providing a welcoming and inspiring environment for all contributors. Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## How Can I Contribute?

### Reporting Bugs

- Use the GitHub issue tracker
- Search for existing issues before creating a new one
- Include as much detail as possible: steps to reproduce, expected vs actual behavior, your environment

### Suggesting Enhancements or Research Ideas

- Open an issue with the appropriate label (enhancement, research-idea, etc.)
- Clearly describe the idea and why it aligns with our mission

### Pull Requests

1. Fork the repository
2. Create your feature branch (`git checkout -b feature/your-amazing-idea`)
3. Commit your changes with clear messages
4. Push to the branch
5. Open a Pull Request

We encourage small, focused PRs and will provide constructive feedback.

### Development Setup

As projects are added to the repository, setup instructions will be included in their respective READMEs or a root DEVELOPMENT.md.

## Style & Quality Guidelines

- Write clear, well-commented, and testable code
- Follow existing code style and patterns in the project
- Be kind, patient, and constructive in code reviews and discussions
- Prioritize scientific rigor and clarity

## Questions?

Feel free to open a GitHub Discussion or comment on relevant issues. We're here to collaborate!

Thank you for helping build the future of scientific discovery! 🚀
